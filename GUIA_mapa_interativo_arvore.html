Abra os ramos para acompanhar cada comparação. Em cada nó, a árvore testa uma variável; no ramo esquerdo segue quando a condição é verdadeira (≤), no direito quando é falsa (>). As folhas mostram a temperatura estimada.

1. Entradas do modelo

Os índices abaixo são os números usados pela árvore para escolher qual entrada comparar.

feature[0]Temperatura instantâneaTemp. Ins. (C) · °C
feature[1]Umidade instantâneaUmi. Ins. (%) · %
feature[2]Radiação solarRadiacao (KJ/m²) · kJ/m²
Saída: Temperaturas alvos, em °C. A folha alcançada contém o valor previsto pelo modelo.
Critério de divisão

squared_error (redução do erro quadrático / variância dos alvos).

Configuração registrada

max_depth=None, min_samples_leaf=1, min_samples_split=2, splitter=best.

2. Explore a árvore

A árvore começa no nó 0. Expanda um nó de decisão para ver os caminhos SIM e NÃO. Você não precisa abrir tudo de uma vez.

SIM: entrada ≤ limite NÃO: entrada > limite Folha: previsão final

3. Como transformar a árvore em lógica C

Exemplo real do primeiro nó da árvore. A tabela completa mais abaixo contém os demais 177 nós.

// Nó 0: feature_index = 1 → umidade instantânea
if (umidade <= 92.5f) {
    // seguir para o nó 1
} else {
    // seguir para o nó 124
}
Nó de decisão

Leia a entrada indicada por feature_index, compare com limite e escolha filho_esquerdo (≤) ou filho_direito (>).

Folha

Quando chegar a uma folha, retorne previsao como temperatura estimada em °C. Não faça outra comparação.

IDs dos nós

Os números dos nós são identificadores para navegar na árvore. Não representam a ordem dos sensores nem a ordem de execução no código.

Precisão numérica

Não arredonde limites ou previsões ao implementar. Use os valores completos da tabela/CSV para manter o comportamento próximo ao modelo Python.
